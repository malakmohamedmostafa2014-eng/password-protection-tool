
**فكرة التطبيق:** تطبيق متخصص في الأمن السيبراني، يساعد المستخدمين على حماية حساباتهم من خلال فحص قوة كلمات المرور، وإنشاء كلمات مرور عشوائية آمنة، والتوعية بمخاطر الاختراق والتصيد الإلكتروني.

**المميزات:** فحص القوة، توليد كلمات المرور، اختبارات تفاعلية، نقاط وشارات، ونصائح للحماية.

**التقنيات:** HTML وCSS وJavaScript.

**الأمان:** تتم معالجة كلمات المرور محليًا داخل المتصفح دون إرسالها أو حفظها.

**الهدف:** نشر الوعي بالأمن السيبراني وحماية البيانات الشخصية.
**Project Idea:** A cybersecurity application that helps users protect their accounts by checking password strength, generating secure random passwords, and raising awareness about hacking and phishing risks.

**Features:** Password strength checker, password generator, interactive quizzes, points and badges, and security tips.

**Technologies:** HTML, CSS, and JavaScript.

**Security:** Passwords are processed locally in the browser without being sent or stored.

**Goal:** To raise cybersecurity awareness and protect personal data.
